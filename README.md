## 📖 概要

デザインは20年かけて「美しさ」から経営アジェンダへと昇格した。マッキンゼーはデザイン成熟度の高い企業が売上成長で32ポイント業界平均を上回ることを証明し、英国デザイン経済は974億ポンドのGVAを創出した。

しかし、その上昇を牽引したデザインファーム自体が逆説的に衰退した。IDEOは売上3億ドルから1億ドルへ崩壊し、70以上のデザインファームが買収された。

そして今、生成AIがデザインの第二の、より根本的な再定義を迫っている。

本書は、この激変の構造を1つのレンズで読み解く。

**デザインとビジネスは別の学問ではない。本質を見抜き構造化するという同一の思考プロセスの、異なる表現形に過ぎない。生成AIが実行を奪った今、この共通の根幹——「眼」——こそがAI時代に残る唯一の武器である。**

本書は全6章で構成される。

| --- | -------------------------- | -------------------------------------------------------------------- |
| 第1章 | 同じ眼で、世界が違って見える             | BTC人材としての越境体験から到達した発見——デザインとビジネスは同一の思考プロセスの異なる表現形である。本書全体を貫く「レンズ」の提示 |
| 第2章 | デザインがビジネスを変えた時代            | IDEO、ティム・ブラウン、スタンフォードd.school。「眼」がビジネスに持ち込まれ、経営アジェンダへ昇格した20年史        |

| 第4章 | 生成AIが奪ったもの、奪えなかったもの        | 実行の価値崩壊と「眼」の不可侵性。クロス、ショーン、ドルストのデザイン理論が予言した構造                         |
| 第5章 | 二項対立の崩壊——デザインとビジネスが1つになる地点 | 「クリエイティブ vs ロジカル」「右脳 vs 左脳」——偽りの境界線が消え、頂点では1つに収束する                   |
| 第6章 | AI時代のデザイン戦略家               | 「眼」の4ステップ実践論。Depth & Velocityとの接続。テクノロジーの位置づけとBTC人材の希少性              |
